이미지 기반 콘텐츠를 관리하고 해당 콘텐츠에서 애니메이션을 수행할 수 있도록 허용하는 객체

선언

class CALayer : [NSObject](https://developer.apple.com/documentation/objectivec/nsobject)

- 인스턴스프로퍼티

## isHidden

레이어가 표시되는지 여부를 불린값으로 나타내는 프로퍼티

선언

var isHidden: [Bool](https://developer.apple.com/documentation/swift/bool) { get set }

- 인스턴스프로퍼티

## masksToBounds

서브레이어가 레이어경계까지 잘렸는지 여부를 불린값으로 나타내는 프로퍼티

선언

var masksToBounds: [Bool](https://developer.apple.com/documentation/swift/bool) { get set }

디폴트값은 false

- 인스턴스프로퍼티

## cornerRadius

레이어의 배경에 대해 둥근 모서리를 그릴 때 사용할 반지름의 크기

선언

var cornerRadius: [CGFloat](https://developer.apple.com/documentation/coregraphics/cgfloat) { get set }
