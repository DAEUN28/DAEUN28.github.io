### **let 상수명: Selector = #selector(함수)**

### -> ex) let timeSelecctor: Selector = #selector(ViewController.updateTime)

### -

타이머가 구동되면 실행할 함수지정

### **Timer.scheduledTimer(timeInterval: 타이머 간격, target: 동작될 view, selector: 타이머가 구동될때 실행할 함수, userInfo: 사용자 정보, repeats: 반복 여부)**

### -> ex) Timer.scheduledTimer(timeInterval: interval, target: self, selector: timeSelector, selector: timeSelector, userInfo: nil, repeats: true)

### **let 상수명 = NSDate()**

### -> ex) let date = NSDate()

- 현재 시간을 NSDate() 함수를 사용하여 가져옴

### **let 상수명 = DateFormatter()**

### -> ex) let formatter = DateFormatter()

- 날짜를 출력하기 위해 DateFormmater클래스의 상수 선언

### **상수명.dateFormat = "표현할 데이터 포맷의 형식"**

### -> ex) formatter.dateFormat = "yyyy-MM-dd HH:mm:ss EEE"

- dateFormat 속성을 설정
