### 1. 리턴버튼을 누르면 키보드 내리기

- 인스턴스메서드

## textFieldShouldReturn(_:)

텍스트 필드에서 리턴버튼을 눌렀을 때 어떤 동작을 실행할 지 델리게이트에게 요청하는 메서드(?)

선언

optional func textFieldShouldReturn(_ textField: [UITextField](https://developer.apple.com/documentation/uikit/uitextfield)) -> [Bool](https://developer.apple.com/documentation/swift/bool)

리턴버튼을 눌렀을 때 기본 동작을 실행할 경우 true

다른 동작을 실행할 경우 false

텍스트 필드는 사용자가 리턴버튼을 누를 때마다 이 메서드 호출

이 메소드를 사용하면 텍스트 필드에서 리턴버튼을 누를 때 실행되는 동작들을 지정할 수 있음

+ 인스턴스메소드

## touchesBegan(_:with:)(UIResponder)

화면에서 하나 이상의 새로운 터치 이벤트가 발생했음을 알리는 메서드

선언

func touchesBegan(_ touches: [Set](https://developer.apple.com/documentation/swift/set)<[UITouch](https://developer.apple.com/documentation/uikit/uitouch)>, with event: [UIEvent](https://developer.apple.com/documentation/uikit/uievent)?)

+ UIView의 인스턴스메서드

## endEditing(_:)

호출한 뷰가 첫번째 응답자 상태(가장 위에 실행되고 있는 뷰(?))를 종료하도록하는 메서드

선언

func endEditing(_ force: [Bool](https://developer.apple.com/documentation/swift/bool)) -> [Bool](https://developer.apple.com/documentation/swift/bool)

호출한 뷰가 첫번째 응답자 상태에서 종료되었다면 true, 아니라면 false
