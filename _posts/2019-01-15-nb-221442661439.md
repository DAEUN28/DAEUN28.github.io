인터페이스에 하나의 이미지 또는 여러개의 이미지들을 일련의 애니메이션 이미지로 표시하는 개체.

### 1. 순서를 가진 이미지들을 애니메이션하기

이미지 뷰는 애니메이션 이미지 시퀀스를 저장하고 해당 시퀀스의 전부 또는 일부를 재생할 수 있다.

이미지들을 [UIImage](https://developer.apple.com/documentation/uikit/uiimage)객체 배열로 지정하고 속성에 할당한다 .

일단 할당되면 이 클래스의 메서드와 속성을 사용하여 애니메이션 타이밍을 구성하고 애니메이션을 시작하고 중지 할 수 있다.

- 인스턴스프로퍼티

## animationImages

애니메이션에 사용할 UIImage배열

선언

var animationImages: [[UIImage](https://developer.apple.com/documentation/uikit/uiimage)]? { get set }

배열에는 UIImage객체가 있어야함

배열에서 같은 이미지객체를 한번 이상 사용할 수 있음

- 인스턴스프로퍼티

## animationDuration

배열에 저장된 모든 이미지들을 모두 한번씩 나타냈을 때 걸리는 시간

선언

var animationDuration: [TimeInterval](https://developer.apple.com/documentation/foundation/timeinterval) { get set }

지속시간은 초 단위로 측정됨

기본값 : 0.0

- 인스턴스메소드

## startAnimating()

이미지의 애니메이션을 시작하는 메소드

선언

func startAnimating()

항상 배열에 첫번째에 저장되어 있는 이미지부터 애니메이션을 시작함

- 인스턴스메소드

## stopAnimating()

이미지의 애니메이션을 중단하는 메소드

선언

func stopAnimating()

- 인스턴스프로퍼티

## isAnimating

애니메이션의 실행상태를 bool값으로 반환

선언

var isAnimating: [Bool](https://developer.apple.com/documentation/swift/bool) { get }

애니메이션이 실행중일 경우 true

실행중이 아닐 경우 false
