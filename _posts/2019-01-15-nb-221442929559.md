## **Text Field**

*Placeholder*

: 입력예문

*Clear Button*

: 누르면 텍스트 필드 안의 텍스트들이 모두 지워지는 버튼

- Never appears - 표시X

- Appears while edting - 편집할 동안만 표시

- Appears unless edting - 입력완료했고 해당 텍스트 필드를 편집하지 않는 동안만 표시

+Clear when edting begins - 편집을 새로 시도할 때 텍스트 필드 안의 텍스트들이 모두 지워짐

- 비밀번호 텍스트필드에 주로 사용

## **Text Input Traits**

*Keyboard Type*

: 키보드 타입

- ASCII Capable - 표준 ASCII 문자를 표시하는 키보드

- Numbers and Punctuation - 숫자와 점 키보드

- URL - URL 입력에 최적화된 키보드 ( 마침표, 슬래시, .com문자열)

- Number Pad - PIN 입력을 위해 설계된 숫자 키패드

- Phone Pad - 전화번호 입력을 위해 설계된 키패드

- Name Phone Pad - 사람의 이름이나 전화 번호를 입력할 수 있는 키패드

- E-mail Address - 전자 메일 주소를 입력하기 위해 최적화 된 키보드

- Decimal Pad - 숫자와 소수점이 있는 키보드

- Twitter - 트위터 텍스트 입력에 최적화 된 키보드(골뱅이, 해시)

- Web Search - 웹 검색 용어 및 URL 입력에 최적화 된 키보드

- ASCII Capable Numer Pad - ASCII 숫자만 출력하는 숫자 패드

+Secure Text Entry - 입력과 동시에 ●와 같이 보이지 않게 표시

- 비밀번호 텍스트 필드에 주로 사용
