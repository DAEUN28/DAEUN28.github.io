### **이미지를 저장할 변수의 이름 = UIImage(named: "이미지 파일명")**

### -> ex) img = UIImage(named: "1.png)

### -

UIImage 타입의 변수에 이미지파일을 저장

### **이미지 뷰의 아웃렛 변수.image = 이미지 파일을 저장한 변수**

### -> ex) imgView.image = img

### -

이미지 뷰가 변수에 저장된 이미지를 보여 줄 수 있게 함

### **이미지 뷰의 아웃렛 변수.frame.width**

### -> ex) imgView.frame.width

- 이미지 프레임의 가로크기

### **이미지 뷰의 아웃렛 변수.frame.height**

### -> ex) imgView.frame.height

- 이미지 프레임의 세로크기

### **이미지 뷰의 아웃렛 변수.frame.size = CGSize(width: 새로운 프레임의 가로크기를 담은 변수, height: 새로운 프레임의 세로크기를 담은 변수)**

### -> ex) imgView.frame.size = CGSize(width: newWidth, height: newHeight)

- CGSize 메서드를 사용하여 이미지 뷰의 프레임 크기를 변경

### **버튼의 아웃렛변수.setTitle("새로운 텍스트", for: .normal)**

### -> ex) btnResize.setTitle("확대", for: .normal)

### -

버튼의 텍스트를 normal 상태의 새로운 텍스트로 변경

### **+ 객체의 크기 쉽게 변환하기**

option을 누른채 마우스를 객체 바깥으로 옮기기!

### **+ 이미지 뷰의 뷰모드**

1. Scale to Fill : 기본 설정 값, 이미지 뷰의 크기에 맞게 이미지의 가로,세로 비율이 변경됨, 비율이 맞지 않으면 뭉개져 보임

2. Aspect Fit : 이미지의 가로, 세로 비율은 유지하면서 이미지 뷰의 크기에 맞게 이미지 크기를 바꿈

3. Aspect Fill : 이미지의 비율은 유지하면서 이미지 뷰를 채움, 이미지 뷰와 이미지 비율이 맞지 않으면 이미지가 넘쳐서 잘릴 수 있음

4. Center : 이미지의 원본 크기를 유지한 채 이미지의 중앙을 이미지 뷰에 출력

5. Top : 이미지의 원본 크기를 유지한 채 이미지의 윗부분을 이미지 뷰에 출력

6. Bottom : 이미지의 원본 크기를 유지한 채 이미지의 아랫부분을 이미지 뷰에 출력

7. Left : 이미지의 원본 크기를 유지한 채 이미지의 왼쪽부분을 이미지 뷰에 출력

8. Right : 이미지의 원본 크기를 유지한 채 이미지의 오른쪽부분을 이미지 뷰에 출력

### **+ viewDidLoad 함수란?**

- 내가 만든 뷰를 불러왔을 때 호출되는 함수

- 부모클래스인 UIViewController클래스에 선언되어 있음

- 뷰가 불려진 후 실행하고자 하는 기능이 필요할 때 이 함수 내에 코드입력
