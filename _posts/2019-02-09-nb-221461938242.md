- 액세서리뷰 만들기

액세서리뷰는 일반 뷰에 추가적으로 붙는 뷰라고 생각하면 된다.

액세서리뷰를 추가하는 방법은 총 네 개의 단계만으로 가능하다.

1. 액세서리뷰로 사용될 뷰와 동작될 오브젝트들을 배치한다.

2. 추가된 뷰와 오브젝트들의 속성을 지정한다.

3. 추가된 뷰와 오브젝트들을 코드와 연결한다.

4. 터치 등의 제스처에 실행될 메소드를 선언한다.

- SQL 구문

SQL이란 데이터베이스에 사용하는 질의 언어이다.

데이터베이스와의 대화를 위해 만들어진 언어이므로, 상당히 구조적으로 만들어져있다.

구조적이라는 것은 공통도니 규칙이 적용된다는 것과도 비슷한 의미이다.

학습자 입장에서는 공통된 규칙 몇 개만 익히면 기본적인 내용을 사용할 수 있게 된다.

SQL문을 학습하는 이유는 다양한 데이터베이스 엔진들을 사용하기 때문이다.

CRUD : 데이터 처리 과정에서 Create(생성), Read(읽기), Update(갱신), Delete(삭제)를 묶어서 일컫는 말

간단한 구문 알아보기

쓰기: INSERT INTO 테이블명 (열 이름) VALUES (값);

읽기: SELECT 열 이름 FROM 테이블명 WHERE 열 이름 = 값 ORDER BY 번호 ASC;

수정: UPDATE 테이블명 SET 열 이름 = 값 WHERE 열 이름 = 값;

삭제: DELETE FROM 테이블명 WHERE 열 이름 = 값;

- 싱글톤 패턴이란 무엇인가

특정클래스에 대해서 객체가 하나만 생성되록 보장하는 방법이다.

특정 클래스의 값을 여러 클래스에서 공유해야 한다거나, 하나씩 순서대로 처리할 때 주로 사용된다.

사용자 설정값은 여러 객체에서 각각의 값을 저장하기 보다는 앱 전체에서 하나의 값으로 관리되어야 한다.

싱글톤 패턴의 좋은 점은 현재의 객체를 보고 있는 다른 클래스에서도 싱글톤 객체가 공유되는 것이다.

- 제스처 인식하기

제스처란 사용자가 디바이스에게 보내는 신호이다.

버튼 등은 기본적으로 이 신호를 받아 이벤트를 처리하도록 되어 있다.

우리는 뷰 등을 탭했을 때 특정 이벤트가 실행되길 원할 때가 있다.

제스처를 인식하는 클래스의 기본 클래스는 UIGestureRecognizer이다.

코드 작성을 할 때는 제스처별로 구체화된 서브 클래스들을 사용하게 된다.

UITapGestureRecognizer : 화면을 탭할 때 사용된다.

UIPanGestureRecognizer: 터치, 드래그 앤 드롭에 사용된다.

UIPinchGestureRecognizer: 두 터치 사이 거리 변화를 인식한다. 주로 확대, 축소 등에 사용된다.

UISwipeGestureRecognizer: 상하좌우로 쓸어 넘기기에 사용된다.

UIRotationGestureRecognizer: 두 터치와 화면 간의 회전을 인식한다. 주로 객체의 회전 등에 사용된다.

UILongPressGestureRecognizer: 탭을 길게 할 때 사용된다.

UIScreenEdgePanGestureRecognizer: 화면 가장자리에서의 드래깅 인식에 사용된다.

제스처를 인식하는 과정은 대부분 세 단계의 과정을 거치게 된다.

1. 제스처 이벤트를 인식하면 어떠한 메서드를 실행할지 선언하는 과정

2. 제스처 이벤트를 인식할 오브젝트를 연결하는 과정

3. 실행될 메서드의 구체적인 기능을 구현하는 과정

+ iCloud 관련기능

key-value storage: 클라우드에 적은 양의 데이터를 키-값 형태로 저장할 때 사용한다.

e-book 앱 같은 경우 보던 페이지를 저장해놨다가 다른 기기에서 앱을 실행했을 때 보던 페이지를 이어서 제공하는 것이 가능하다.

iCloud Documents: 데이터 파일을 iCloud에 저장한다. 저장한 파일은 동일한 계정의 다른 기기에서도 전송받아 사용할 수 있다.

CloudKit: iCloud 서버에 접근해서 DB같은 구조화된 데이터를 저장하고 관리할 수 있게 하며, 동일한 앱을 사용하는 사용자가 공유할 수 있는 데이터 공간을 제공한다.

- 현지화 작업

현지화 : 하나의 앱에서 디바이스의 언어 설정에 따라 앱의 내용을 제공하는 것

현지화작업의 순서

1. 사용 언어를 추가한다.

2. 언어별로 구체적인 내용을 작성한다.

3. 디바이스 언어를 변경하고 테스트
